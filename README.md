# Streamlit + Google Sheets Leaderboard

**Created:** 2023-03-19

## Problem
Wanted a leaderboard that non-developers could update from Google Sheets.

## Solution
A Streamlit app connected to Google Sheets as the data source.

## Outcome
Rankings can be updated in Sheets and shown in a friendly web UI.
